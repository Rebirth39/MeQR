# Android CP/CB 标签

仅支持世界计划分组中与 iOS 一致的 20 位角色。长按已添加的角色标签，拖到另一角色标签中央，松手后选择 CP 或 CB。拖动来源在左、目标在右；拖到边缘或其他分组标签上仍为排序。取消弹窗不改变原标签及顺序。

CP 使用双方代表色实心底和白字；CB 使用不透明白底、2dp 双色描边和双方代表色文字。标签配色里的 CP/CB 按钮可以修改类型，B 右侧的 ↔ 按钮交换左右位，同时保留字重与类型。普通配色设置不能覆盖组合样式。组合或交换遇到同名、同身份冲突时不覆盖已有标签。

TagReference 的可选 pairing 字段保存类型、两位角色的目录 ID、五语姓名快照和代表色。旧数据不含此字段时仍按普通标签读取；无效组合降级为普通标签。JSON 保存、备份、编辑预览副本以及 ProfileSyncClient 的导入导出均保留 pairing。同步字段结构与 iOS CardTagPair 一致；本地测试不代表已经完成线上跨设备同步验收。既有交换码协议仍以普通标签传递，不保证组合属性和外观。

TagPairInstrumentation 必须使用以 .tagpaircheck 结尾的独立 applicationId 和对应测试 runner。测试覆盖 760 种有序组合、冲突拒绝、五语及离线快照、旧数据、JSON 和同步 DTO、本地保存重开，以及真实长按拖动、取消、类型切换、左右位按钮与两种卡片模板。普通 Tag 回归使用现有 TagInputInstrumentation 的独立包。

2026-10-20 的构建、签名、测试日志、源码前后快照、独立测试 init.gradle 和截图存放在 Documents/Codex/android-cp-cb-20261020。正式 APK 保持版本 1.6.0 / 18，供本地测试使用，未发布到官网。
