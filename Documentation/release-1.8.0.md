# 喜劳转扩 1.8.0（build 31）测试说明

日期：2026-10-26。1.8.0 的 QQ 人装饰仍为**本地原型**，仅保存在本机，不参与同步或在线交换。

## 新功能：QQ 人装饰

- 每张卡最多 3 张透明底人物图。
- 入口：**编辑卡片 → QQ人装饰**。
  - 选图后可用滑杆调旋转（10° 一档）和大小（60%–125%），角度旁有 ↑ / ↓ 按钮做 1° 微调。
  - 点 **「在卡面上调整」**：设置页收起，回到首页卡片直接编辑。
  - 卡面上支持单指拖动、双指捏合缩放、双指旋转；缩放/旋转范围与设置页一致。
  - 安全区（头图、二维码、通行证/选择器、Tag）按卡片真实 UI 动态测量；图片落在安全区内的面积不得超过自身的 30%，超出会回弹并提示。
  - 右上角 **「完成」** 退出编辑。
- 老卡片没有保存过位置时，按左上 / 右上 / 右下默认锚点显示。

## 建议测试

1. 选 1–3 张透明 PNG，调整角度和大小，确认小窗预览与实际卡面一致。
2. 在卡面上拖动到四角与安全区边缘，确认橙色安全区贴合头图、二维码、通行证、Tag 的真实位置。
3. 放大到 125%、旋转到 ±180°，确认限制生效、手势跟手、翻面不卡。
4. 故意把 QQ 人拖进二维码/头图，确认超过 30% 会回弹并出现提示。
5. 点「完成」后用双指捏合/旋转再试一次，确认松手才写回，拖动过程中预览不卡。
6. 杀掉 App 重开，确认位置、角度、大小都保留。
7. 做一次本机备份导出/恢复，确认装饰数据仍在。
8. 确认装饰不会出现在在线交换或跨设备同步里。

## 已知边界

- 安全区目前按卡面实际布局动态测量，覆盖标准卡与罗德岛卡的主要区域；其它模板或极端字号下可能不完整。
- 每个 QQ 人有 60pt 透明触控光晕；两个装饰靠得很近时，可能优先命中上层。
- Android 端的 1.8.0 实现尚未与本次 iOS 的自由摆放/卡面编辑完全对齐。
